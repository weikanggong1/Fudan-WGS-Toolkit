# Fudan WGS Toolkit

> 本工具尚在开发验证阶段，未达到原软件精度，切不可作为真实分析使用的标准化工具。

Fudan WGS Toolkit 使用 PyTorch GPU 完成单变异、gene-based coding、noncoding 和 ncRNA 关联分析。`prepare_WGS_data` 从原始 PLINK 文件与独立功能注释准备遗传数据；`run_WGS_all` 读取表型 CSV、协变量 CSV 和完成的遗传目录，输出每个表型独立目录的结果 CSV。已有完成目录可直接分析，无需再次转存。

单表型和多表型使用同一个入口。多个表型共享遗传读取、缓存和设备传输，各自处理缺失样本、协变量和零模型；支持单卡或多卡、稀疏 GRM 或无亲缘结构模型，以及验证完成块后的恢复。运行和数据准备均使用 Python。

`rm_nan=True` 默认填补表型：二分类只保留 1 为病例，其余数值和缺失为 0；连续表型缺失用该表型有效母样本的均值填补。`rm_nan=False` 使用 available 样本。协变量不填补；默认所有表型用协变量文件的全部列，可以共享完全相同的设计矩阵 X。显式逐表型定制时只检查各自选用的协变量。回归系数、残差与检验投影独立。改变缺失处理后使用新的结果目录并重新拟合零模型。

`host_memory_limit_gib=None` 自动读取物理主存与所有有限 cgroup 祖先限制；显式上限由同一节点的全部 GPU worker 共享，不按卡数相乘。共享主机内存依据实际占用和尚未分配的工作区准入；当前样本集合遇到资源压力时保留此前已提交的结果。只读索引、遗传块和模型缓存有明确容量，临时张量在批次结束后释放。

普通关联状态与显著结果的 FP64 SPA 来源共用按真实存储字节计量的模型 LRU，准备新工作区前释放未使用的缓存。较小 gene mask 可在 GPU 上直接从原始六状态块整理 FP32 基因型，减少主机往返；长 mask 继续使用有界 panel。每个表型保留自己的样本、频率筛选、缺失填补和统计模型。

统一入口默认按全局固定表型 tile 分配 GPU：先汇集样本行序完全相同的表型，再按 `trait_batch_size` 切成固定批次，每个表型归一张卡计算全部染色体。tile 的表型编号、样本行序和边界绑定科学计划，恢复时可重新分配 GPU 所有权并复用已完成块。每个 worker 内继续共享遗传读取；报告区分全局唯一遗传作业数与各卡实际扫描次数。表型或 tile 数较少时，部分 GPU 可以空闲，报告保留实际使用情况。

零模型拟合按严格输入绑定复用设计矩阵、GRM 子集和亲缘谱；同尺寸家系块批量求解，每个表型仍独立优化。缓存和工作区有界，批次随实时资源余量缩小。

关联阶段在单个模型与 mask 内复用有界 panel 整理、旋转和协变量投影；原 LOBPCG 的独立权重求解使用一个 worker 生命周期内的两路固定 CUDA stream。不同表型仍分别构造检验协方差，原随机起点、收敛规则、谱细化和尾概率分支保留。资源不足时使用原顺序路径。

已发布的关联 panel 与谱求解源码 `0071b370` 通过 2,530 项 CUDA 回归测试，零失败、零跳过。共同样本和 available 样本两组各 16 个真实表型均完成四类局部分析，与冻结参考的概率差异为 0；与已认证独立单表型结果的最大 |Δ−log10(P)| 为 0.0000313。一个连续与一个二分类表型的六个真实小 mask 与官方同配置单表型流程对照，57 个 P 字段的最大 |Δ−log10(P)| 为 0.000190032，全部低于 0.001。同卡四模型、四类局部工作集的两个暖轮墙时降低 11.00%，包含 CSV 写出与完整回读；预热后持续运行 30.82 分钟，轮末显存保持平台，关闭时实际持有者和租约归零。该版的精度、计时与持续内存记录见使用说明 7.1。

本轮新增 Single 同步 CSV 写出、同一物理块的位点标签复用和 FP64 SPA Newton 导数复用。writer 专项使用 1,056 条真实记录，每次显式重放 512 次，两组交换参考／候选顺序；写入中位墙时降低 11.46%，含完成回读降低 10.28%，gzip 字节一致。实际进程在写入后、提交前中断，再恢复的 1,056 行逐字段一致、重复行数为 0。已保存模型的消费范围收据单独校验来源、加载接口和数组结构，不作为新拟合器等价证明。上述耗时只覆盖已有结果的输出，四模型整组配对未测到净加速。2,604 项 CUDA 回归、两组 16 模型局部精度及预热后 31.43 分钟内存平台检查通过；同配置既有官方对照的 57 个 P 字段最大 −log10P 差异为 0.00019004，属于少数 mask 的局部覆盖。详见 [验证记录 7.2](docs/fudan_wgs_toolkit.md#72-single-输出标签与-spa-迭代优化)。

## 安装

```bash
git clone https://github.com/weikanggong1/Fudan-WGS-Toolkit.git
cd Fudan-WGS-Toolkit
conda env create -f environment.yml
conda activate fudan-wgs-toolkit
```
