## 精度

- 遗传数据准备核对完整样本顺序、等位基因方向、基因型状态、整数计数和注释；数值压缩不能改变这些内容。
- 关联精度对照固定样本、表型处理、协变量、零模型、GRM、遗传方向、注释与 mask。报告全部有限 P 值及任一路径 `P<0.05` 的显著并集，目标为 `|Δ(−log10 P)|<0.001`。
- 极小概率使用有限的原生 log P 比较。没有可验证 log P 的下溢零值单独报告，不用人为 floor 算作通过。
- 同输入 Python 实现对照、官方软件对照和不同人群的官方已发布结果比较分别报告。共享样本或读取不代表不同表型共用检验矩阵。
- 官方求根失败回退与本包收敛结果不同的列单独列出，用原累积量、尾概率公式和独立求根器复核，保留未修改官方输出的原始差异。不能将其计为直接官方输出一致。
- 最新有限二分类测试的[匿名汇总](binary_bounded_20261013.anonymous.json)分别保存官方比较、旧 / 新实现比较、结果组装与性能范围。

## 速度与资源

端到端时间注明是否包含输入读取、零模型拟合、关联、写出和最终回读。GPU 阶段使用 CUDA event 或明确同步边界；嵌套阶段、并行 worker 和子进程时间不相加为端到端。

资源记录区分 GPU allocated / reserved / 阶段峰值、CPU RSS / PSS、节点 cgroup 与可用主存。共享设备的整卡占用不自动归属于项目，短时端点平稳不等于长期内存平台已通过。真实工作集、缓存冷热和共享资源条件随表格说明。

## 完整运行

函数返回 `completed=True` 还应对应实际 worker 成功退出、覆盖完整的提交块、无遗漏或重复的结果、CSV 完整回读和完成凭据。进程存在、已开始任务、partial CSV、局部精度检查或组件测试均不作为全量完成指标。

公开文档仅保留匿名汇总和方法说明，真实身份、表型名称、位点、gene / mask 结果表及运行配置保存在私有证据中。

## 合成输入

`generate_simulated_data` 用固定种子生成完全虚构的输入，再通过正常数据准备和关联入口运行。它适用于不访问真实数据的代码回归、速度比较、内存压力测试及同输入优化前后 `−log10(P)` 比较。生成系数不是 oracle P 值，合成输入上的数值一致不替代真实数据或官方同输入精度验证。合成与真实 benchmark 分别记录数据来源、规模、实际 mask M、阶段和资源，不能直接外推彼此的端到端时间。

2026-10-16的完整GPU输入为1024名人工样本、两条染色体各256个变异，每类3个表型；四次运行分别验证二分类available / 缺失填0及连续available / 均值填补。每次24个表型×染色体×分析类型组合，30份gzip CSV均核对SHA、CRC、行数和Single样本数。10万人检查仅完成1024个变异的生成与正常准备，没有运行该规模的关联。公开记录不包含生成的样本、位点或基因表。
