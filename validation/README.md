## 精度

- 单样本原始预处理固定 FASTQ 顺序、参考、RG、已知位点、筛选和工具配置，完整比较 BQSR 表、SAM 核心字段与 typed AUX、gVCF/VCF 字段和 PLINK 基因型。原 CPU 输出是实现对照，不是生物学真值集；读段前缀和局部调用区间的通过不等于完整深度 WGS 验收。
- 遗传数据准备核对完整样本顺序、等位基因方向、基因型状态、整数计数和注释；数值压缩不能改变这些内容。
- 关联精度对照固定样本、表型处理、协变量、零模型、GRM、遗传方向、注释与 mask。报告全部有限 P 值及任一路径 `P<0.05` 的显著并集，目标为 `|Δ(−log10 P)|<0.001`。
- 极小概率使用有限的原生 log P 比较。没有可验证 log P 的下溢零值单独报告，不用人为 floor 算作通过。
- 同输入 Python 实现对照、官方软件对照和不同人群的官方已发布结果比较分别报告。共享样本或读取不代表不同表型共用检验矩阵。
- 官方求根失败回退与本包收敛结果不同的列单独列出，用原累积量、尾概率公式和独立求根器复核，保留未修改官方输出的原始差异。不能将其计为直接官方输出一致。
- 最新有限二分类测试的[匿名汇总](binary_bounded_20261013.anonymous.json)分别保存官方比较、旧 / 新实现比较、结果组装与性能范围。

## 速度与资源

端到端时间注明是否包含输入读取、零模型拟合、关联、写出和最终回读。GPU 阶段使用 CUDA event 或明确同步边界；嵌套阶段、并行 worker 和子进程时间不相加为端到端。

资源记录区分 GPU allocated / reserved / 阶段峰值、CPU RSS / PSS、节点 cgroup 与可用主存。共享设备的整卡占用不自动归属于项目，短时端点平稳不等于长期内存平台已通过。真实工作集、缓存冷热和共享资源条件随表格说明。

## 完整运行

函数返回 `completed=True` 还应对应实际 worker 成功退出、覆盖完整的提交块、无遗漏或重复的结果、CSV 完整回读和完成凭据。进程存在、已开始任务、partial CSV、局部精度检查或组件测试均不作为全量完成指标。

公开文档仅保留匿名汇总和方法说明，真实身份、表型名称、位点、gene / mask 结果表及运行配置保存在私有证据中。

## 合成输入

`generate_simulated_data` 从私有汇总校准或显式的 small 人工预设直接生成生产格式 prepared，再由正常关联入口读取。它适用于不访问真实数据的代码回归、速度比较、内存压力测试及同输入优化前后 `−log10(P)` 比较。生成系数不是 oracle P 值，合成输入上的数值一致不替代真实数据或官方同输入精度验证。合成与真实 benchmark 分别记录数据来源、规模、实际 mask M、阶段和资源。

默认 reference 的逐染色体位点数、频谱和官方15类mask目标来源于私有汇总，不发布原始身份、坐标或基因结果。改变 n 时保持目标 MAF，MAC 及实际合格 M 可因整数化和样本筛选变化，应保存目标 / 实际审计。已发布 mask 行匹配与未发布类别的推断行分开记录，未知类别不能当成 M=0，也不能把额外推断行算作已发布目标的重复。完整数量校准、资源准入、有限规模生成与完整GPU关联分别报告。

[当前存储标准化记录](storage_standard_20261016.anonymous.json)包含307项CPU测试、真实文件大小只读核查、有限真实帧无损重编码、8,192位点实际生成 / 普通prepare，以及用户批准后在共享GPU上完成的旧 / 新两版各4种入口验证；120份CSV解压字节相同。完整参考只做2,112个人工位点的压缩探测外推，未生成全部数据，预测和磁盘实测分开报告。旧13.2 TiB数值是宽松未压缩预留被误标为输出预测，已在功能文档中更正。

[前一direct prepared记录](simulated_prepared_20261016.anonymous.json)保留当时267项测试、参考n下15条目标M匹配，以及n缩小时低MAC取整 / M变化和当时GPU未运行的历史状态；不作为当前存储布局与GPU验证的记录。
